### Сутності та атрибути
- User(Користувач): id, username
- Game(Гра): id, name, description
- ItemCatalog(Каталог предметів): id, name, description
- Item(Предмет): id, name, description
- InventoryPosition(Позиція інвентаря):id, quantity(натуральне число)
- Character(Персонаж): id, character_name
Усі id є UUID. Усі інші атрибути за замовчуванням є текстовими, якщо інше не вказано явно. 

### Зв'язки
- Користувач може бути власником багатьох ігор, ігра може мати одного власника (1:N)
- У грі може бути багато персонажів, але персонаж є частиною лише однієї гри (1:N)
- У користувача може бути багато персонажів, але персонаж належить лише одному користувачу (1:N)
- Гра може ссилатися на декілька каталогів, декілька ігор можуть використовувати один каталог (N:M)
- Один предмет може належати одному каталогу, в одному каталозі може бути багато предметів (1:N)
- Користувач може створити багато каталогів, в одного каталога може бути лиже один власник (1:N)
- Позиція інвентаря може мати тільки один предмет, але один предмет може належати багатьом позиціям (1:N)
- Персонаж може мати скільки завгодно позицій, але позиція може належити лише одному персонажу (1:N)
